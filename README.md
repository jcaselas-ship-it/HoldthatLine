# Hold that Line

Juego de lápiz y papel de Sid Sackson (*A Gamut of Games*): entre los dos jugadores dibujáis una sola línea recta tramo a tramo; pierde quien hace la última jugada. Contra la IA (Fácil/Normal), 2 jugadores en el mismo dispositivo u online con PeerJS. Tableros 4×4, 5×5 y 6×6. Instalable como PWA.

**Jugar:** https://jcaselas-ship-it.github.io/HoldthatLine/
